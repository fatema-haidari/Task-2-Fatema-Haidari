# Expense Tracker 

A simple Python program that allows users add their expenses with tile and amount and calulates the total amount.

## Features

- Allows the user add an expenses with a title and an amount
- Generates a csv file to store the labeled data
- Allows users to add multiple expenses 
- Adds data to the existing scv file
- Reads data from the scv file
- Calculates the total amount
- Shows all expenses and amounts 

## Technologies Used

- Python
- sys module
- os module
- csv file

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python expense_tracker.py
